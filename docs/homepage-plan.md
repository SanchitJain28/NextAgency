## 🏗️ Page Sections (In Order)

---

### 1. 🔵 Hero Section
**Purpose:** Instant value prop + primary keyword placement + CTA above the fold.

**SEO Role:**
- H1 must contain the primary keyword: `"Expert Shopify Development Agency"`
- Supporting subheading covers long-tail: *"Custom Shopify Apps, Headless Commerce & Theme Development for Scaling Brands"*
- Schema: `WebPage` + `Service` structured data on this section
- LCP element (above-the-fold image/headline) should load in < 2.5s

**Visual Content:**
- Bold headline with gradient text
- 2–3 line subheadline that explains what we do + who for
- Two CTAs: `"Get a Free Audit"` (primary) + `"See Our Work"` (secondary)
- A subtle animated background — no heavy libraries, pure CSS or lightweight canvas
- Optional: Floating pill badges like `"Shopify Plus Partner"`, `"50+ Stores Built"`, `"India's #1 Shopify Agency"`

**Copy:**
> **H1:** Expert Shopify Development Agency
> **Subhead:** We build blazing-fast Shopify stores, custom apps, and headless experiences that convert — for brands that are done settling for average.

### 9. 🤝 Process Section
**Purpose:** Reduce friction for potential clients. Explains how working with us looks.
