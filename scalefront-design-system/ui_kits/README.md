# ScaleFront UI Kit

This directory contains applied interface kits extracted from the ScaleFront homepage source. Each kit is a reusable Claude Design package.

## Kits

- **[app/](./app/)** — Component kit with button, card, and navigation components. See `app/README.md` for the full kit structure, component files, usage workflow, design notes, and source basis.

## Reuse Guide

Pick a kit from the list above, then read its README for component specs and reuse instructions. Every kit documents the applied kit structure, component files, usage workflow, design notes, and source basis so future agents can reuse it like a Claude Design package.
