# Headless WooCommerce vs Traditional WooCommerce: Which Setup Makes Sense?

## What is Headless woocommerce

- In a headless wocommerce architecture the frontend and backend of the application / website is separated specifically the frontend is on Nextjs / React (Any js/ts framework) and backend on the wordpress/ woocommerce itself . Where in the monolithic woocommerce i.e the tradition woocommerce website , both frontend and backend remain in a single PHP application.

## What will change when you will shift from traditional woocommerce website to headless woocommerce website

### Frontend

- In headless woocommerce frontend is made using JS frameworks such has NextJS or any other framework . this gives you the flexibilty to do custom changes on the frontend , on the other hand in wordpress, you simply drag and drop from the website builder which does not gives much flexibilty

### API Usage

- In tradition woocommerce api connection are handled by PHP itself like php functions , but in headless woocommerce we have to connect to woocommerce rest api or graphql api to get live product data and other ecommerce objects

### Performace

- Performace difference depends upon several factor , an optimized , unbloated woocommerce theme can outperforn an non optimized
  headless woocommerce store, so it depends upon the store functionality and the optimizations

### SEO

- In traditional woocommerce SEO is handled by plugins like YOAST SEO etc which handles techincal SEO and on page for SEO , where as in headless woocommerce we have to make custom functions which handles techinical .

## When headless makes sense ?

### if you have multiple channels you operate on , then headless woocommerce makes sense

### if you need custom functionality on the frontend which are not available in wordpress , then it makes much sense to shift on headless woocommerce

## When traditional woocommece makes sense ?

### For most ecommerce websites traditional woocommece makes sense because most of the functionalities can be covered by wordpress ecosystem
