# WooCommerce to Shopify migration image prompts

Generate **six images only: one cover and five selected section images**. These support the most important migration risks without adding an image to every section.

## Text density note

Keep text minimal and let visuals explain the process. Prefer a short title and brief labels. Keep detailed explanations in the article.

Paste [agent-instruction.md](agent-instruction.md) into Google Flow’s agent instructions. Each individual prompt includes an approved set of labels and a word limit. Do not shrink the font to fit extra copy. If the composition feels crowded, simplify the visual rather than adding annotations. Check spelling and URL accuracy before exporting.

| --- | --- | --- |
| [00-cover.md](00-cover.md) | Cover and blog header | 1600 × 900 px |
| [01-products-and-collections.md](01-products-and-collections.md) | Product and collection mapping | 1600 × 1000 px |
| [02-customers-and-orders.md](02-customers-and-orders.md) | Customer and order dependencies | 1600 × 1000 px |
| [03-subscription-cutover.md](03-subscription-cutover.md) | Subscription billing cutover | 1600 × 1000 px |
| [04-seo-redirect-map.md](04-seo-redirect-map.md) | Relevant URL redirects | 1600 × 1000 px |
| [05-migration-launch-checklist.md](05-migration-launch-checklist.md) | Migration phases and launch checks | 1600 × 1000 px |

Each file contains a copy-ready static image prompt, suggested placement, and alt text. These are explanatory diagrams, not evidence of client results. Do not add fabricated performance figures, migration success rates, guaranteed rankings, or unsupported platform capabilities.

## What to paste as the image prompt

Copy everything under “Google Flow prompt” in the selected file, including both the shared visual style paragraph and the specific diagram instructions. The first paragraph alone describes the style; it does not describe the image to generate. Paste the separate agent instruction into Google Flow’s agent instructions field.
