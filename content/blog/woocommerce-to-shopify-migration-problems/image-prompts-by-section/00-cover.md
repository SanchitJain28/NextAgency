# Cover: WooCommerce to Shopify migration

Dimensions: 1600 × 900 px (16:9).

Placement: Blog cover and header.

Suggested alt text: WooCommerce to Shopify migration overview showing data, store setup, and launch checks.

## Google Flow prompt

Create a static editorial diagram for a practical ecommerce migration blog. White background, near-black text, thin gray borders, restrained orange accents, clean sans-serif typography. Use simple flat icons, clear arrows, generous whitespace, and large mobile-readable labels. No decorative dashboard, tiny annotations, paragraphs, invented results, statistics, client logos, or promises of loss-free migration. Generate a still image, not a video.

Use a clear left-to-right composition: a generic store labeled “WooCommerce” on the left, a generic store labeled “Shopify” on the right, and three small visual checkpoints between them. Use product boxes for “Map data”, a cart with a check for “Test store”, and a branching URL arrow for “Plan redirects”. Above the composition, use the title “WooCommerce to Shopify migration”. Do not imply that transferring data alone completes the migration. Only use these six quoted text labels. Maximum 25 words total.
