## Google Flow prompt

Create a still editorial diagram for a technical ecommerce blog. Use a white background, near-black text, thin gray outlines, restrained orange accents, and flat illustrations. Use the supplied headings and supporting copy with readable type and clear spacing.

Create an illustrated checklist titled “Move a live WooCommerce store to Next.js”. Use a spacious layout of five connected cards. Give each card its heading and the accompanying action line:

- “Audit the current store” / “List plugins, checkout methods, and important URLs.”
- “Build on staging” / “Connect WooCommerce and build catalog, cart, and account flows.”
- “Test real purchases” / “Check variations, stock, shipping, coupons, and payments.”
- “Prepare SEO” / “Keep existing URLs where possible and redirect changed URLs.”
- “Launch and monitor” / “Plan rollback and watch checkout errors, orders, and indexing.”

Use illustrations that reinforce the actions. Keep the text on each card large enough to read without enlarging the image.
