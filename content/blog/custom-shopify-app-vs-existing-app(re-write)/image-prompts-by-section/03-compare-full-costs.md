# Compare the full costs

Dimensions: 1600 × 1000 px (8:5).

Placement: After the cost comparison list in “Development cost vs app subscription cost”.

Suggested alt text: A cost comparison includes subscriptions, usage fees, and manual work for an existing app and development, hosting, and upkeep for a custom app.

## Google Flow prompt

Use a white background, near-black text, thin gray outlines, restrained orange accents, and flat illustrations. Create a still image with clear spacing and readable type. Use the supplied labels and short explanations.

Create a two-column comparison titled “Compare costs over the same period”. Give each column a short checklist:

- “Existing app” / “Subscription and usage fees” / “Configuration and support terms” / “Staff time spent on workarounds”.
- “Custom app” / “Discovery, development, and testing” / “Hosting and monitoring” / “Maintenance and API updates”.

Below the columns, show a shared strip labeled “Include migration work where it applies.” Use checklists and simple icons with no prices, charts, or break-even figures. Keep both options visually neutral so the reader compares their own costs.
