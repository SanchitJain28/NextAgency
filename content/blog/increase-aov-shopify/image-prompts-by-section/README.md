# Shopify AOV image prompts

Apply the Google Flow settings from [image-config.json](image-config.json). Paste [the agent instructions](agent-instruction.md) into the project’s agent instructions field, then paste the contents of each prompt file into Flow.

The config also records the recommended publication dimensions, placement, and alt text. The section images have an 8:5 publication target. Allow room at the sides of the 16:9 composition if you plan to crop to that target.
