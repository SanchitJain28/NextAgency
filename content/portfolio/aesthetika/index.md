# Project Aesthetika

- Developed the website frontend and integrated the backend with the frontend , frontend follows a responsive layout and designed for mobile first expirience.

- Integrated frontend to backend , made several custom metafeilds to store information like product descroption , and other product details , integrated Shopify cart drawer to improve the CRO of the website as the cart drawer shows related product and addons

- For checkout : I integrated one click checkout for fast checkout expiernces which substinattly increase the coversion rate by reducing the friction in the checkout process.

- On collection page : I used infinite scroll feature to improve the UX of the website and to reduce the number of page loads

## Pages i developed

- Home page
- Dynamic product pages
- Collection pages with advanced filtering
- Advanced cart drawer for improving the CRO of the website
- One click checkout integration for fast checkout expiernces

## Website SEO

- I made sure product page has proper meta title , meta description and a SEO friendly slug and made sure that images are optimized because optimized images helps in improving the core web vitals of the website , TIP : to make sure images are optimized , the should be in WebP format

- Proper structured data on product page for rich snippet in google search results , structured data is also helps to cite the product in Ai chatbots like chatgpt

- FAQs : Added Faqs on home page and product page , for common user question which helps to users to take decision and improves trust for the website, it also helps in AEO
